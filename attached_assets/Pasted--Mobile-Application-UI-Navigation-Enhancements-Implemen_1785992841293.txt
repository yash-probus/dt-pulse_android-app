# Mobile Application UI & Navigation Enhancements

Implement the following UI and UX improvements across the mobile application. These changes are focused on improving screen utilization, navigation, and usability while keeping all existing functionality intact.

---

# 1. Login Screen Layout Optimization

The current login screen allocates too much vertical space to the KESCO branding, which pushes the login form toward the bottom of the screen. Redesign the layout to achieve a more balanced appearance.

## Header Branding

The branding should appear in the following order:

1. **KESCO Logo**
2. **Kanpur Electricity Supply Company Limited**
3. **A Government of U.P. Undertaking**
4. **DT Pulse Application Logo**

### KESCO Branding

- Reduce the size of the KESCO logo while keeping it visually prominent.
- Reduce the font size of the company name proportionally.
- Keep the KESCO branding as the primary headline of the screen.
- Maintain adequate spacing between the logo, company name, and tagline.

### DT Pulse Branding

Below the KESCO branding, display the DT Pulse application logo.

- Increase its size slightly compared to the current implementation so it is clearly visible.
- Maintain proportional spacing between the KESCO branding and the DT Pulse logo.
- The DT Pulse logo should clearly represent the application branding without overpowering the KESCO branding.

---

## Login Card Position

Reposition the login card so that it sits approximately in the vertical center of the screen instead of near the bottom.

The login card should contain:

- Login ID
- Password
- Show/Hide Password (Eye icon)
- Remember Me checkbox
- Sign In button

Maintain existing validation and authentication functionality.

---

## Footer

Restore the footer branding that was previously available.

The footer should contain:

- Powered by **Probus** logo
- Legal
- Contact & Support
- Version Number (e.g. Version 1.1)

The footer should remain visible at the bottom of the screen with proper spacing and should not overlap the login form.

---

# 2. Profile Screen Improvements

## Move Profile Access

Remove the **Profile** icon from the bottom navigation bar.

Replace the existing **Light/Dark Mode Toggle** in the top-right corner with a **Profile** icon.

When the user taps the Profile icon, it should open the existing Profile screen.

The mobile application no longer requires a Light/Dark mode switch.

---

## Bottom Navigation

After removing Profile, the bottom navigation should contain only:

- Home
- Sync
- Logs

Maintain equal spacing between the remaining navigation items.

---

## Logout Button Visibility

Currently, the Logout button is not fully visible because it appears below the fold.

Update the Profile screen layout so that:

- The Logout button is always visible without excessive scrolling.
- The screen should scroll naturally if content exceeds the viewport.
- The final action buttons should not be clipped by the bottom safe area.
- Respect device safe area insets for all screen sizes.

---

# 3. DT Analyzer Dashboard Enhancements

## Add Hierarchy Filters

Above the **DT Overview / Sensor Overview** segmented toggle, add three hierarchy filters.

Order:

```
Circle
Division
Sub-Division
```

These filters should appear on a single row, matching the desktop application's hierarchy filter style.

Example:

```
All Circles ▼

All Divisions ▼

All Sub-Divisions ▼
```

---

## Default Values

On first load:

- Circle = All Circles
- Division = All Divisions
- Sub-Division = All Sub-Divisions

---

## Filter Dependency

Implement cascading hierarchy selection.

### Circle

Selecting a Circle filters the available Divisions.

### Division

Selecting a Division filters the available Sub-Divisions.

### Sub-Division

Displays only Sub-Divisions within the selected Division.

---

## Dashboard Filtering

Changing any hierarchy filter should update:

### DT Overview

- Total DTs
- Live DTs
- Inactive DTs
- Under Outage
- DT Rating Status graph
- Active Alerts

### Sensor Overview

- All Sensor KPI cards
- Sensor Status by Type graph
- Active Alerts

Only data belonging to the selected hierarchy should be displayed.

---

## Layout

The screen order should become:

```
Dashboard Tabs

Hierarchy Filters
(Circle | Division | Sub-Division)

DT Overview / Sensor Overview Toggle

Dashboard KPI Cards

Charts

Active Alerts
```

The hierarchy filters should remain fixed directly above the DT Overview / Sensor Overview toggle and use the same visual style as the existing dropdown components.
